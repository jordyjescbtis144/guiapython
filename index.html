1. print() — Mostrar información

print() es la instrucción para mostrar algo en pantalla. Todo lo que va dentro de los paréntesis aparece en el panel Run de PyCharm.

Ejemplo 1.1 — Un solo mensaje de texto (archivo print1.py) 
print("Bienvenidos a la clase de Python")

Explicación paso a paso:

  1. print es una función que ya trae Python — solo se usa, no hay que crearla.
  2. Los paréntesis () son obligatorios: adentro va lo que se quiere mostrar.
  3. El texto está entre comillas dobles porque es un string (texto). Las comillas indican "muestra esto tal cual está escrito".
  4. Al ejecutar (▶️ o Shift+F10), el texto aparece en el panel Run sin las comillas — las comillas nunca se muestran, solo marcan dónde empieza y termina el texto.

Así se ve en el panel Run:

Bienvenidos a la clase de Python
Ejemplo 1.2 — Varios datos en un mismo print (archivo print2.py) 
print("Nombre:", "Diana", "Edad:", 17)

Explicación paso a paso:

  1. Dentro de print() se pueden poner varias cosas separadas por comas ,.
  2. Python imprime cada elemento uno tras otro, agregando un espacio automático entre cada uno — no hace falta escribir esos espacios.
  3. Aquí hay dos textos ("Nombre:" y "Diana", con comillas) y un texto más con un número ("Edad:" y 17, este último sin comillas porque es un dato numérico, no texto).
  4. print() puede mezclar textos y números en la misma instrucción sin ningún problema.

Así se ve en el panel Run:

Nombre: Diana Edad: 17
Ejemplo 1.3 — Print con una operación matemática adentro (archivo print3.py) 
print("Total con descuento:", 100 - 20)

Explicación paso a paso:

  1. No solo se pueden poner textos y números sueltos: también se puede poner una operación matemática completa dentro de print().
  2. Python primero resuelve la operación 100 - 20 (da 80), y después la imprime junto con el texto.
  3. Esto es útil porque no necesitas calcular el resultado tú mismo y escribirlo a mano — Python lo calcula en el momento de ejecutar el programa.
  4. El orden importa: si cambiaras a 20 - 100 el resultado sería -80, no 80.

Así se ve en el panel Run:

Total con descuento: 80

2. input() — Pedir información al usuario

input() hace lo opuesto a print(): detiene el programa y espera a que la persona escriba algo y presione Enter. Lo que escribe siempre se guarda como texto, aunque haya tecleado números.

Ejemplo 2.1 — Pedir un dato y saludar (archivo input1.py) 
nombre = input("Como te llamas? ")
print("Mucho gusto,", nombre)

Explicación paso a paso:

  1. input("Como te llamas? ") muestra ese texto en la consola como pregunta, y el programa se detiene esperando respuesta.
  2. Lo que el usuario escriba (y confirme con Enter) se guarda en la variable nombre, porque está a la izquierda del signo =.
  3. El signo = aquí significa "guarda lo de la derecha en la variable de la izquierda" — no es una igualdad matemática.
  4. La segunda línea se ejecuta después de que el usuario respondió, y usa el valor guardado en nombre.
  5. Si el usuario escribe Diana, la primera línea del panel Run muestra la pregunta + lo que tecleó, y la segunda línea es lo que imprimió el programa:

Así se ve en el panel Run:

Como te llamas? Diana
Mucho gusto, Diana
Ejemplo 2.2 — Convertir el texto a número y calcular (archivo input2.py) 
edad = input("Cuantos anios tienes? ")
edad = int(edad)
print("Naciste aproximadamente en el anio", 2026 - edad)

Explicación paso a paso:

  1. Regla importante: todo lo que devuelve input() es texto (tipo str), aunque el usuario escriba solo números.
  2. Si se intentara restar directamente después del input() sin convertir, Python marcaría un error, porque no se puede restar un número a un texto.
  3. edad = int(edad) convierte ese texto en un número entero. Aquí se reutiliza el mismo nombre de variable: primero guarda el texto, y en la siguiente línea se sobreescribe con el número ya convertido.
  4. La última línea usa edad (ya convertida) para calcular 2026 - edad, y ese cálculo se hace dentro del mismo print().
  5. Si el usuario escribe 17, el resultado es 2026 - 17 = 2009:

Así se ve en el panel Run:

Cuantos anios tienes? 17
Naciste aproximadamente en el anio 2009
Ejemplo 2.3 — Dos input() trabajando juntos (archivo input3.py) 
base = float(input("Base del rectangulo (m): "))
altura = float(input("Altura del rectangulo (m): "))
print("El area es:", base * altura, "metros cuadrados")

Explicación paso a paso:

  1. Se pueden usar varios input() en un mismo programa, uno por cada dato que se necesite — aquí se piden dos: base y altura.
  2. Se usa float() en vez de int() porque float permite números con punto decimal (por ejemplo 3.5); int() solo acepta números enteros y marcaría error si el usuario escribe un decimal.
  3. Cada input() se guarda en su propia variable (base y altura), y ambas están disponibles para usarse después, en cualquier orden.
  4. La fórmula del área de un rectángulo (base × altura) se calcula directamente dentro del print() final.
  5. Con base=5 y altura=3, el área es 15.0 (con .0 porque float() siempre trabaja con decimales, aunque el resultado sea un número "redondo"):

3. if — Tomar una decisión simple

if ("si") le permite al programa decidir: ejecutar un bloque de código solo cuando se cumple una condición. En esta sección se usa if solo, sin elif ni else todavía — lo importante aquí es entender que, si la condición es falsa, el programa simplemente no ejecuta esa parte y sigue de largo.

Ejemplo 3.1 — Revisar si un número es positivo (archivo if1.py) 
numero = int(input("Escribe un numero: "))
if numero > 0:
    print("El numero es positivo")

Explicación paso a paso:

  1. Primero se pide el número y se convierte a entero con int(), igual que en la sección anterior.
  2. if numero > 0: le pregunta a Python "¿es verdad que numero es mayor que 0?".
  3. Los dos puntos : al final de la línea if son obligatorios — sin ellos PyCharm marca error.
  4. La línea print(...) tiene 4 espacios de sangría antes: esa sangría le dice a Python "esta línea pertenece al if, solo se ejecuta si la condición es verdadera". PyCharm la agrega solo al presionar Enter después de los dos puntos.
  5. Con numero = 8: la condición 8 > 0 es verdadera, así que sí se imprime el mensaje:

Así se ve en el panel Run:

Escribe un numero: 8
El numero es positivo

Con numero = -4, la condición es falsa. El programa NO tiene ningún else, así que simplemente no imprime nada y termina:

Escribe un numero: -4
Ejemplo 3.2 — Avisar solo cuando se cumple algo (archivo if2.py) 
horas = int(input("Cuantas horas estudiaste? "))
if horas >= 3:
    print("Vas muy bien preparado")

Explicación paso a paso:

  1. >= significa "mayor o igual que". La condición se cumple con 3 horas o más.
  2. Igual que antes: si la condición es verdadera, se ejecuta la línea de adentro (con sangría); si es falsa, Python la salta por completo.
  3. Este if no tiene ninguna instrucción para el caso contrario — si el alumno estudió menos de 3 horas, el programa simplemente no dice nada al respecto.
  4. Con horas = 4, la condición 4 >= 3 es verdadera:

Así se ve en el panel Run:

Ejemplo 3.3 — Comparar una respuesta de texto (archivo if3.py) 
respuesta = input("Te gusta programar? (si/no): ")
if respuesta == "si":
    print("Genial, sigamos aprendiendo")

Explicación paso a paso:

  1. input() siempre devuelve texto, así que aquí no hace falta convertir nada con int() o float().
  2. == (dos signos de igual) es el operador que compara si dos valores son iguales — es distinto del signo = que se usa para guardar un valor en una variable.
  3. respuesta == "si" compara el texto que escribió el usuario contra el texto exacto "si". Si el usuario escribe Si con mayúscula o sí con acento, la comparación sería falsa, porque Python distingue mayúsculas, minúsculas y acentos.

4. elif — Varios caminos posibles

elif es la forma corta de "si no, pero si..." (viene de else if). Se usa cuando hay más de dos caminos posibles y cada uno depende de una condición distinta. Un mismo if puede ir seguido de varios elif. Python revisa las condiciones en orden, de arriba hacia abajo, y en cuanto una es verdadera, ejecuta ese bloque y ya no revisa las demás.

Ejemplo 4.1 — Clasificar una temperatura (archivo elif1.py) 
temperatura = int(input("Temperatura en grados: "))
if temperatura <= 0:
    print("Hace mucho frio")
elif temperatura <= 15:
    print("Hace fresco")
elif temperatura <= 25:
    print("Clima agradable")

Explicación paso a paso:

  1. Python revisa primero temperatura <= 0. Si es falsa, no se detiene ahí: pasa a revisar el siguiente elif.
  2. elif temperatura <= 15: solo se revisa si la condición del if de arriba fue falsa. Por eso, aunque diga "menor o igual a 15", en la práctica cubre el rango de 1 a 15 (porque 0 y menos ya se atraparon arriba).
  3. Lo mismo pasa con el segundo elif: cubre de 16 a 25, porque los casos anteriores ya se descartaron.
  4. elif se escribe exactamente en la misma columna que su if, sin sangría entre ellos — así Python sabe que pertenecen a la misma cadena de decisiones.
  5. Aquí no hay else todavía: si ninguna condición se cumple (por ejemplo, si la temperatura es mayor a 25), el programa no imprime nada — esto se ve en el segundo caso de abajo.
  6. Con temperatura = 10 (pasa la primera condición, cae en el primer elif):

Con temperatura = 30: ninguna de las tres condiciones es verdadera (30 no es <=0, <=15 ni <=25), y como no hay else, el programa no imprime nada:

Ejemplo 4.2 — elif comparando textos (archivo elif2.py) 
dia = input("Escribe el dia: ")
if dia == "lunes":
    print("Inicio de semana")
elif dia == "viernes":
    print("Casi terminamos la semana")

Explicación paso a paso:

  1. elif no solo sirve con números: aquí compara textos con ==, igual que se vio en la sección de if.
  2. Si el usuario escribe "lunes", se cumple la primera condición y el elif ni siquiera se revisa.
  3. Si escribe cualquier otro día que no sea "lunes" ni "viernes" (por ejemplo "miercoles"), ninguna condición se cumple y, otra vez, no hay else que atrape ese caso — el programa no imprime nada.
  4. Esto demuestra que elif permite revisar varias opciones sin necesidad de terminar siempre en un else — depende de lo que el programa necesite hacer.

Ejemplo 4.3 — Varias condiciones seguidas (calificación en letra) (archivo elif3.py) 
calificacion = int(input("Escribe tu calificacion: "))
if calificacion >= 90:
    print("Letra: A")
elif calificacion >= 80:
    print("Letra: B")
elif calificacion >= 70:
    print("Letra: C")

Explicación paso a paso:

  1. Aquí hay tres condiciones en cadena: primero se pregunta por la calificación más alta (90+), y solo si esa es falsa se pasa a revisar la siguiente.
  2. Esto es clave: aunque una calificación de 95 también cumpliría calificacion >= 80, Python nunca llega a revisarlo, porque ya encontró una condición verdadera antes (>= 90) y se detuvo ahí.
  3. Por eso el orden de las condiciones en una cadena if/elif importa mucho: siempre hay que poner primero la condición más "específica" o más alta.
  4. Con calificación = 85: falla el primer if (85 no es ≥90), pero sí cumple el primer elif (85 ≥ 80):

5. else — El caso "todo lo demás"

else ("si no") es el bloque que atrapa todo lo que sobra: se ejecuta cuando ninguna de las condiciones anteriores (if y sus elif) fue verdadera. A diferencia de if y elif, else nunca lleva una condición propia. Cuando se usa else, el programa siempre ejecuta alguno de los bloques — nunca se queda sin imprimir nada.

Ejemplo 5.1 — if / else simple (archivo else1.py) 
edad = int(input("Cuantos anios tienes? "))
if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")

Explicación paso a paso:

  1. Es el par más simple: if cubre un caso, else cubre todo lo demás, sin necesidad de escribir otra condición.
  2. if y else se escriben en la misma columna (mismo nivel de sangría), y ambos terminan en dos puntos :.
  3. A diferencia de los ejemplos de elif sin else, aquí el programa nunca se queda callado: con cualquier edad que escriba el usuario, uno de los dos mensajes siempre se imprime.
  4. Con edad = 20 entra al if; con edad = 15 entra al else:

Cuantos anios tienes? 15

Ejemplo 5.2 — if / elif / else con tres caminos (archivo else2.py) 
numero = int(input("Escribe un numero: "))
if numero > 0:
    print("Es positivo")
elif numero < 0:
    print("Es negativo")
else:
    print("Es cero")

Explicación paso a paso:

  1. Aquí se combinan las tres piezas: if revisa el primer caso, elif revisa un segundo caso alterno, y else atrapa lo que quede — en este caso, exactamente cuando el número es 0.
  2. Fíjate que no hace falta escribir la condición numero == 0 en ningún lado: como ya se descartaron "mayor que 0" y "menor que 0", lo único que puede quedar es 0, y de eso se encarga el else automáticamente.
  3. Esto es justamente la ventaja de else frente a agregar otro elif: cuando el último caso es "todo lo demás", no hace falta escribir su condición.
  4. Con numero = 0 no se cumple ni > 0 ni < 0, así que cae en else:

6. while — Repetir instrucciones

while ("mientras") repite un bloque de código una y otra vez, mientras una condición siga siendo verdadera. Python revisa la condición antes de cada repetición (a cada repetición se le llama "vuelta" o "iteración").

Ejemplo 6.1 — Contar del 1 al 5 (archivo while1.py) 
contador = 1
while contador <= 5:
    print("Vuelta:", contador)
    contador = contador + 1
print("Termine")

Explicación paso a paso:

  1. contador = 1 crea la variable que va a llevar la cuenta, empezando en 1.
  2. while contador <= 5: se revisa ANTES de cada vuelta: mientras sea verdadera, se repite el bloque de abajo (con sangría).
  3. Dentro del bloque hay dos líneas: se imprime el valor actual de contador, y luego se le suma 1.
  4. contador = contador + 1 es la línea más importante: sin ella, contador nunca cambiaría, la condición siempre sería verdadera, y el programa se quedaría repitiendo para siempre ("bucle infinito").
  5. Vuelta por vuelta: contador=1 (1≤5, imprime, pasa a 2) → 2 (imprime, pasa a 3) → 3 → 4 → 5 (imprime, pasa a 6) → 6 (6≤5 es FALSO, el bucle se detiene).
  6. print("Termine") no tiene sangría, así que está fuera del while — se ejecuta una sola vez, cuando el bucle ya terminó:

Así se ve en el panel Run:

Vuelta: 1
Vuelta: 2
Vuelta: 3
Vuelta: 4
Vuelta: 5
Termine
Ejemplo 6.2 — Repetir hasta que el usuario escriba una palabra clave (archivo while2.py) 
palabra = ""
while palabra != "salir":
    palabra = input("Escribe algo (o salir): ")
    print("Escribiste:", palabra)
print("Programa terminado")

Explicación paso a paso:

  1. palabra = "" crea la variable con texto vacío antes de preguntar la condición la primera vez — si no existiera todavía, Python no podría revisar while palabra != "salir": desde el inicio.
  2. != significa "distinto de". La condición se lee: "repite mientras lo que escribió el usuario sea distinto de la palabra salir".
  3. Dentro del bucle, cada vuelta vuelve a preguntar con input() y sobreescribe el valor de palabra.
  4. A diferencia del Ejemplo 6.1, aquí no sabemos de antemano cuántas vueltas dará el bucle — depende de lo que decida escribir el usuario.
  5. En cuanto el usuario escribe exactamente salir, la condición se vuelve falsa y el bucle se detiene:

Así se ve en el panel Run:

Escribe algo (o salir): hola
Escribiste: hola
Escribe algo (o salir): salir

Programa terminado
Ejemplo 6.3 — Cuenta regresiva (archivo while3.py) 
contador = 5
while contador > 0:
    print(contador)
    contador = contador - 1
print("Despegue!")

Explicación paso a paso:

  1. Este bucle va al revés del Ejemplo 6.1: empieza en 5 y va restando, en vez de sumando.
  2. while contador > 0: se repite mientras el contador siga siendo mayor que cero.
  3. contador = contador - 1 reduce el contador en 1 cada vuelta, acercándolo poco a poco a la condición de paro.
  4. Vuelta por vuelta: 5 (5>0, imprime, pasa a 4) → 4 → 3 → 2 → 1 (imprime, pasa a 0) → 0 (0>0 es FALSO, se detiene).
  5. Nota que aquí print(contador) imprime directamente la variable numérica, sin ningún texto adicional — print() también funciona con un solo dato.

5
4
3
2
1
Despegue!
